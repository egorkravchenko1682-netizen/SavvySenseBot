# SAVVY SENSE

AI Shopping Decision Engine для СНГ и мирового рынка.

Находит не просто "похожий товар", а лучшую сделку — с учётом
доставки и таможенной пошлины, независимо от того, в каком регионе
находится продавец.

## Архитектура

```
Telegram (bot.py)
      │
      ▼
core.SavvyCore.process(SavvyRequest) -> SavvyResponse
      │
      ├── intent.detector / gift.profile
      │     — обычный поиск товара или подбор подарка по бюджету
      │
      ├── product.identity/dna, product.query
      │     — "Product DNA" (обязательные/опциональные атрибуты,
      │       бюджет, состояние) и план поиска
      │
      ├── search.engine + адаптеры:
      │     ├── marketplaces.wildberries  (BY, RU)
      │     ├── marketplaces.ozon         (RU)
      │     ├── marketplaces.ebay         (мир, официальный API)
      │     ├── marketplaces.aliexpress   (Китай, мир)
      │     ├── marketplaces.alibaba      (Китай, мир, опт)
      │     ├── marketplaces.china1688    (Китай, выкл. по умолчанию)
      │     ├── search.adapters.duckduckgo (общий веб-поиск, фолбэк)
      │     └── search.adapters.demo      (тестовые данные)
      │
      ├── region.groups + region.search_sweep
      │     — опрашивает не только домашний регион пользователя, но
      │       и несколько дополнительных (RU, CN, мир), чтобы найти
      │       тот же товар дешевле в другом регионе
      │
      ├── offer.extractor — разбор товарных страниц (JSON-LD, meta)
      │
      ├── region.currency_normalize — приводит предложения из разных
      │     площадок (рубли, юани, доллары...) к одной валюте, иначе
      │     их нельзя честно сравнить
      │
      ├── region.logistics + region.landed_cost
      │     — оценка доставки/пошлины и полной (landed) стоимости;
      │       результат передаётся в те самые поля (`real_cost`),
      │       которые уже умеет сравнивать `offer.offer_comparator`
      │
      ├── matching.matcher — строгое сопоставление Product DNA и
      │     найденного оффера (EXACT / SIMILAR / REJECTED)
      │
      ├── offer.deal_engine — оценка отфильтрованных офферов:
      │     бюджет, состояние, риск продавца, качество сделки
      │     (SAVVY SCORE) — выбирает лучшее предложение по ВСЕМ
      │     опрошенным регионам и площадкам сразу
      │
      └── gift.recommender — для запросов вида "подарок для..." без
            конкретного товара: перебирает подходящие категории
            (gift.catalog) и оценивает их тем же DealEngine
```

Каждый слой — самостоятельный, тестируемый модуль. `core/orchestrator.py`
— единственное место, которое их соединяет.

## Возможности

- **Поиск по нескольким маркетплейсам одновременно** — Wildberries,
  Ozon, eBay, AliExpress, Alibaba (см. "Маркетплейсы" ниже про
  надёжность каждого)
- **Сравнение цены между регионами** — ищет тот же товар не только
  там, где находится пользователь, но и в РФ, Китае и мире, честно
  считая доставку и таможенную пошлину, а не просто голую цену
- **Подбор подарка по бюджету** — "найди подарок девушке до 3000
  рублей" перебирает подходящие категории подарков и находит лучший
  вариант в бюджете
- анализ ссылок на товар
- поиск более дешёвых альтернатив
- SAVVY SCORE / оценка риска сделки

## Маркетплейсы: что реально работает, а что — best-effort

Это важно понимать перед деплоем — не все источники одинаково надёжны:

| Источник | Регион | Надёжность | Требует |
|---|---|---|---|
| DemoAdapter | все | тестовые данные, не реальные цены | — |
| DuckDuckGo | все (фолбэк) | веб-поиск + `offer.extractor`; может получать 403 при частых запросах | — |
| Wildberries | BY, RU | публичный (неофициальный) API; ломается при смене версии API у WB | — |
| eBay | мир | **официальный** Browse API — самый надёжный из всех | `EBAY_CLIENT_ID`, `EBAY_CLIENT_SECRET` |
| Ozon | RU | внутренний JSON-эндпоинт, активно защищается антибот-системами — может систематически не отвечать | — |
| AliExpress | Китай, мир | парсинг встроенного в HTML JSON; сайт сильно JS-рендерится, риск поломки высокий | — |
| Alibaba | Китай, мир (опт) | парсинг HTML; цены — оптовые, могут зависеть от объёма заказа | — |
| 1688 | Китай | **выключен по умолчанию** — рассчитан на покупателей внутри Китая, обычный сервер почти наверняка получит блокировку | `ENABLE_1688_ADAPTER=1` |

Каждый источник, который перестал отвечать или изменил формат,
просто возвращает пустой список для этого запроса — это никогда не
останавливает поиск по остальным источникам (см. `search/engine.py`).
Если один из best-effort адаптеров перестанет работать после
изменений на стороне площадки — почините разбор ответа в
соответствующем файле в `marketplaces/`, остальной пайплайн трогать
не придётся.

**Разработка велась без доступа к интернету** (песочница без
сетевого доступа) — реальные ответы Wildberries/Ozon/AliExpress/
Alibaba не проверялись вживую, только структура кода и
обработка ошибок. Перед продакшн-запуском стоит проверить каждый
адаптер на реальных запросах.

## Не готово / roadmap

- **Поиск по фото** — `SavvyCore` строит Product DNA из подписи к
  фото, но не делает reverse image search.
- **Сравнение (`compare`) и отслеживание цены (`track`)** —
  распознаются как intent, но используют общий пайплайн поиска;
  отдельная логика "показать бок о бок" и хранилище для отслеживания
  цены не реализованы.
- **Оценка пошлины** — упрощённая эвристика для личного ввоза в ЕАЭС
  (порог 200 EUR, 15% сверх) без учёта веса и накопительного лимита
  за календарный месяц; для UZ/AZ/TJ/MD пошлина всегда считается
  неизвестной (нет уверенной публичной эвристики) — см.
  `region/logistics.py`.
- **1688** нуждается либо в headless-браузере с китайским прокси,
  либо в платном доступе через дата-провайдера, чтобы реально
  работать — сейчас это архитектурная заглушка.

## Переменные окружения

```
BOT_TOKEN=токен Telegram-бота       (обязательно)
SAVVY_REGION=BY                     (регион по умолчанию, опционально)
SAVVY_CURRENCY=USD                  (валюта по умолчанию, опционально)
SAVVY_MAX_RESULTS=20                (опционально)
LOG_LEVEL=INFO                      (опционально)

EBAY_CLIENT_ID=...                  (для marketplaces.ebay)
EBAY_CLIENT_SECRET=...              (для marketplaces.ebay)
ENABLE_1688_ADAPTER=1               (включить best-effort адаптер 1688.com)
```

## Запуск

```
pip install -r requirements.txt
export BOT_TOKEN=...
python bot.py
```

## Поддерживаемые регионы

BY — Беларусь · RU — Россия · KZ — Казахстан · UZ — Узбекистан ·
KG — Кыргызстан · AM — Армения · AZ — Азербайджан · TJ — Таджикистан ·
MD — Молдова

При межрегиональном сравнении также опрашиваются CN (Китай) и WORLD
(остальной мир) — см. `region/groups.py`.

## Важно

Telegram Bot API не передаёт боту точную физическую геолокацию
пользователя автоматически — регион определяется из профиля и текста
запроса.

Оценка доставки и пошлины — это эвристика для сравнения предложений,
а не точный расчёт и не налоговая консультация. Реальная сумма на
таможне может отличаться.
