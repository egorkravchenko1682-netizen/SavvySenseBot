# SAVVY SENSE

AI Shopping Decision Engine для СНГ и мирового рынка.

## Возможности

- поиск товаров обычным языком
- поиск по фотографии
- анализ ссылок
- сравнение товаров
- поиск более дешёвых альтернатив
- BUY / WAIT
- SAVVY SCORE
- персональные предпочтения
- региональный режим СНГ
- поиск сначала в регионе пользователя
- затем по СНГ
- затем по мировому рынку

## Railway Variables

BOT_TOKEN=твой Telegram token

OPENAI_API_KEY=твой OpenAI API key

OPENAI_MODEL=gpt-5.6-luna

DB_PATH=savvysense.db

## Start Command

python bot.py

## Поддерживаемые регионы

BY — Беларусь
RU — Россия
KZ — Казахстан
UZ — Узбекистан
KG — Кыргызстан
AM — Армения
AZ — Азербайджан
TJ — Таджикистан
MD — Молдова

## Важно

Telegram Bot API не передаёт боту точную физическую геолокацию пользователя автоматически.

Регион определяется из профиля и запроса пользователя.

Реальная доступность конкретных маркетплейсов зависит от API, web-доступа и ограничений соответствующих сайтов.
